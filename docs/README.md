## 🎯 项目概述

### 核心目标
开发一个本地优先的桌面应用，实现：
1. **统一接口调用**：通过单一应用调用Moark平台所有模型API
2. **智能模型推荐**：根据用户需求自动推荐最适合的模型
3. **工作流编排**：支持多模型串联的复杂AI工作流
4. **成本优化**：智能调度模型资源，降低使用成本
5. **数据主权**：用户数据完全本地存储，绝对控制权

### 设计原则
- **零服务器成本**：完全本地化应用，无需后端服务器
- **数据主权**：所有数据存储在用户本地
- **隐私保护**：敏感信息本地加密，不上传任何用户数据
- **自动更新**：应用和API接口支持自动更新机制
- **离线能力**：核心功能支持离线使用

## 🛠️ 技术栈

### 桌面应用框架
- **核心框架**：Tauri 2.0（Rust + Web前端）
- **前端框架**：Next.js 15（App Router）
- **UI组件库**：Shadcn/ui + Tailwind CSS 4
- **状态管理**：Zustand（轻量级状态管理）
- **构建工具**：Bun（超快JavaScript运行时）

### 本地数据存储
- **数据库**：SQLite（嵌入式，无需安装）
- **文件存储**：本地文件系统 + 加密
- **缓存系统**：内存缓存 + SQLite缓存表
- **配置存储**：JSON配置文件 + SQLite配置表

### 开发工具
- **设计工具**：Figma + Google Stitch（AI辅助设计）
- **代码编辑器**：VS Code + Rust/TypeScript扩展
- **版本控制**：Git + GitHub
- **CI/CD**：GitHub Actions（跨平台构建）
- **协作工具**：飞书（文档、任务、即时通讯）
