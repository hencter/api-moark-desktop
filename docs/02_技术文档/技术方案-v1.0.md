# Moark聚合应用技术方案

## 1. 系统架构概览

### 1.1 整体架构（本地优先方案）
```
┌─────────────────────────────────────────────────────────────┐
│                   客户端层 (Client Layer)                    │
├─────────────────────────────────────────────────────────────┤
│ 桌面端 (Tauri) │ 移动端 (Flutter) │ 设计工具 (Stitch) │
└─────────────────────────────────────────────────────────────┘
                               │
┌─────────────────────────────────────────────────────────────┐
│                  本地业务层 (Local Business Logic)           │
├─────────────────────────────────────────────────────────────┤
│ API代理 │ 工作流引擎 │ 数据管理 │ 用户配置 │ 本地缓存 │
└─────────────────────────────────────────────────────────────┘
                               │
┌─────────────────────────────────────────────────────────────┐
│                  本地数据层 (Local Data Storage)             │
├─────────────────────────────────────────────────────────────┤
│ SQLite │ 本地文件 │ 加密存储 │ 配置存储 │ 缓存数据 │
└─────────────────────────────────────────────────────────────┘
                               │
┌─────────────────────────────────────────────────────────────┐
│                  外部服务层 (External Services)               │
├─────────────────────────────────────────────────────────────┤
│        Moark API │ 用户自有服务 │ 第三方工具 │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 核心设计原则
1. **数据主权**：所有用户数据存储在本地，用户拥有绝对控制权
2. **零服务器成本**：无需后端服务器，降低运营成本
3. **隐私保护**：敏感数据本地加密存储，不上传云端
4. **离线能力**：核心功能支持离线使用
5. **自动更新**：应用和API接口可自动更新

    // 2. 创建工作流实例
    const instance = this.createInstance(workflow, inputData);
    
    // 3. 拓扑排序确定执行顺序
    const executionOrder = this.topologicalSort(workflow.nodes, workflow.connections);
    
    // 4. 按顺序执行节点

#### 2.3.2 推荐策略实现
```python
# 推荐策略基类
class RecommendationStrategy:
    def recommend(self, user_id: str, context: dict, n: int = 10) -> List[Recommendation]:
        raise NotImplementedError

# 协同过滤策略
class CollaborativeFilteringStrategy(RecommendationStrategy):
    def __init__(self, user_item_matrix):
        self.user_item_matrix = user_item_matrix
        
    def recommend(self, user_id: str, context: dict, n: int = 10) -> List[Recommendation]:
        # 基于用户-物品交互矩阵计算相似度
        similar_users = self.find_similar_users(user_id)
        recommendations = self.generate_recommendations(user_id, similar_users)
        return recommendations[:n]

# 内容推荐策略
class ContentBasedStrategy(RecommendationStrategy):
    def __init__(self, item_features):
        self.item_features = item_features
        
    def recommend(self, user_id: str, context: dict, n: int = 10) -> List[Recommendation]:
        # 基于物品特征和用户历史偏好计算相似度
        user_profile = self.build_user_profile(user_id)
        recommendations = self.calculate_similarity(user_profile, self.item_features)
        return recommendations[:n]

# 混合推荐策略
class HybridStrategy(RecommendationStrategy):
    def __init__(self, strategies: List[RecommendationStrategy], weights: List[float]):
        self.strategies = strategies
        self.weights = weights
        
    def recommend(self, user_id: str, context: dict, n: int = 10) -> List[Recommendation]:
        all_recommendations = []
        
        # 执行所有策略
        for strategy in self.strategies:
            recommendations = strategy.recommend(user_id, context, n * 2)
            all_recommendations.extend(recommendations)
            
        # 加权融合
        fused_recommendations = self.fuse_recommendations(all_recommendations)
        return fused_recommendations[:n]
```
