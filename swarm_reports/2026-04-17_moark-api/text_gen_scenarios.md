## 一、接口功能能力概述

模力方舟提供三个核心文本生成接口，均兼容 OpenAI 风格 API：

| 接口路径 | 功能定位 | 典型场景 |
|----------|-----------|----------|
| /chat/completions | 对话补全 | 智能对话、AI 助手、客服机器人 |
| /completions | 文本补全 | 续写生成、内容扩展、文案创作 |
| /messages | 消息处理 | 消息理解、结构化输出 |

### 1.1 /chat/completions 接口能力

- 对话式交互：支持多轮对话上下文，消息角色包括 system、user、assistant
- 流式响应：支持 stream=True 实现实时输出，减少等待时间
- 工具调用：支持 Function Calling，可与外部系统交互
- 结构化输出：通过 guided_json 参数指定 JSON Schema 输出格式
- 风格控制：通过 temperature、top_p 等参数控制生成随机性

### 1.2 /completions 接口能力

- 文本续写：基于给定提示（prompt）生成连贯续写内容
- 上下文感知：精准理解输入文本的语义、逻辑和风格
- 多场景适配：支持句子补全、段落续写、文档扩充、格式填充
- 流式输出：支持实时获取补全结果

### 1.3 /messages 接口能力

- 消息理解：对输入消息进行深度语义理解
- 结构化响应：支持按指定格式输出处理结果

## 四、总结

模力方舟文本生成 API 具备以下核心能力：

1. 多接口覆盖：/chat/completions、/completions、/messages 覆盖主流场景
2. OpenAI 兼容：降低接入成本，支持主流开发框架
3. 模型丰富：涵盖通用、推理、专业领域等多种模型
4. 功能完善：流式响应、函数调用、结构化输出等能力成熟

建议产品规划重点：

- 优先落地智能客服和写作助手场景，市场需求明确
- 构建场景化 Prompt 模板库，降低用户使用门槛
- 提供完整的技术方案和最佳实践文档
- 设计灵活的定价策略满足不同用户群体
